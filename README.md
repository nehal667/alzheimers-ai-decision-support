**AI-Based Alzheimer’s Disease Prediction and Decision Support System**



Overview

This project implements a Perceptron-based AI model for Alzheimer’s disease prediction using medical and lifestyle data.



Features

\- Data preprocessing

\- Data analytics and visualization

\- Perceptron machine learning model

\- Human-AI decision support system

\- Bias reduction techniques



Technologies Used

\- Python

\- Scikit-learn

\- Pandas

\- Matplotlib

\- Seaborn

\- Google Collab



Model

Perceptron Classifier



Dataset

Alzheimer’s Disease Dataset from Kaggle
